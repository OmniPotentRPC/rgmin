Added unrestarted matrix-free GMRES with right preconditioning: `gmres_right` for one right-hand side and `gmres_right_block` for several independent ones whose Arnoldi directions share one batched operator call per iteration. Operators and preconditioners are fallible, every iteration streams to a `KrylovObserver`, and every reported residual is the true `‖b - A x‖` in the original system rather than the Givens estimate.
Refusals are typed (`KrylovRefusal`) and carry the full `KrylovRecord` collected before them. A zero Arnoldi subdiagonal with a nonzero rotated diagonal is an invariant subspace, not a refusal: the run returns `Converged` when the true residual meets the tolerance and `Stagnated` otherwise. When the rotated diagonal vanishes as well, the projected system is singular and is refused as `SingularProjectedSystem`; that refusal, like a non-finite rotation refused as `NonFinite`, ends its record with an iteration that carries the true residual of the unchanged iterate. A non-finite value anywhere in the solve, including a NaN residual or a residual target `rtol ‖b‖` that overflows, is refused as `NonFinite` before it can report `Converged`, and the block solver refuses exactly what the scalar solver refuses.
The error types implement `Display` and `std::error::Error`, and `GmresOptions`, `KrylovIteration`, `KrylovRecord` and `GmresRun` are non-exhaustive with `Default` and `with_*` setters.
The restarted flexible `fgmres`, its `Fgmres` options and report types, and `EisenstatWalker` are unchanged.
