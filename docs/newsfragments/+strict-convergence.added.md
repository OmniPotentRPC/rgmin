- `Control::with_require_convergence` opts into `Error::NotConverged(Box<Report>)` when a finished run is still above `gtol`. The default stays `Ok`. `Report.converged` is the `gtol` comparison. C ABI minor 50 and layout revision 6 add the control field, the report flag, `RGMIN_NOT_CONVERGED`, and `rgmin_solver_set_require_convergence`. Python `minimize(require_convergence=True)` raises `NotConverged` and the exception carries the report. `OptimizeResult.success` is unchanged when the flag is off.
