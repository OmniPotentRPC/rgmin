Added `rgmin.optimize.ODE12r`, `MDMin`, `PreconLBFGS` and `PreconFIRE`. `ODE12r` follows the ASE 3.29 class (`rtol` 0.01, extrapolate-3 step length, no per-atom cap). `MDMin` is a session method, `mdmin`, at ABI minor 70: the time step is `istep`, the per-atom cap is the session atom cap, and a positive `maxmove` also caps the Euclidean length of the step. `PreconLBFGS` and `PreconFIRE` follow ASE 3.29: `None` and `'ID'` leave the metric off, `'Exp'` installs the exponential metric on a Cartesian 3N layout, and `precon='auto'` keeps ASE's small-system rule. Any other preconditioner kind raises `ValueError`. A restart file written by any of the four replays in a new optimizer of the same class.
