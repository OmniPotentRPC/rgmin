`rgmin_lowest_eigenpairs_ex` reports each pair's residual `||Hv − θv||` and a converged flag, and takes an optional preconditioner callback. A null preconditioner is the identity and matches `rgmin_lowest_eigenpairs` bit for bit. `rgmin_eigenpair_t` keeps the minor-39 layout. Python `lowest_eigenpairs` returns residuals and converged flags. `strict=False` returns those flags instead of raising `RuntimeError`. `precond` is a callable on an `(n, m)` block. ABI minor 42.
