`CellFilter` relaxes Cartesian positions and the periodic cell together. `CellFilter::frechet` stores the ASE Frechet block `exp_cell_factor * log(cell_factor * F)`, and `CellFilter::deformation` stores the `UnitCellFilter` block `cell_factor * F`. Both factors default to the number of atoms. The value is the enthalpy `E + P V`, and the gradient is its derivative, including an external scalar pressure. `with_mask` holds entries of the deformation gradient at the identity. `with_hydrostatic_strain` keeps the cell a scalar multiple of the reference cell. Existing optimizers minimize the wrapper unchanged, and every previous constructor keeps its default.
