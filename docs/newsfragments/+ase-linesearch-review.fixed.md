An updated BFGS inverse Hessian keeps its pairs when `h0` is set again, and a refused constrained BFGS step restores `h0 I`. A non-positive ASE `maxstep` scales each increment, so zero leaves the trial where it started, and a non-finite increment is not evaluated. `rgmin_solver_set_ase_linesearch` opts a default L-BFGS session into the plain Wolfe step. A zero direction or an empty position fails the ASE search before any evaluation. A `BFGSLineSearch` or `LBFGSLineSearch` restart counts the evaluations it replays, so `force_calls`, `function_calls`, and the logged force-call column continue from the recorded run.
