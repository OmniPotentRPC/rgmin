A start outside the bounds of the run is clipped before the first step, and every front end now measures a no-move L-BFGS run from that clipped point. `Solver::run` and `Solver::run_gauged` measured from the start as given, and Python `minimize` from a copy of `x0` taken before the clip, so a run that never left the clipped point was `MaxIter` or `Stop.BUDGET` there and `LineSearchFailed` or `Stop.LINE_SEARCH` from `minimize_method` and the C one-shots. All of them report the line search stop now.
