The C ABI reference and `include/rgmin.h` now document that librgmin re-exports the eindir-core C ABI (`eindir_core_abi_compatible`, `eindir_core_abi_family`, `eindir_core_abi_stamp`, `eindir_core_version`, `eindir_last_error` and the `eindir_objective_` functions `new`, `free`, `eval`, `grad`, `has_grad`, `dim`, `bounds_low` and `bounds_high`) as public API. A C caller of `rgmin_minimize_eindir` that links only librgmin builds its objective and ABI stamp through these names, which librgmin has exported since 0.7.0. The export check in CI now fails when one of them goes missing or when eindir-core exports a name not on that list.
