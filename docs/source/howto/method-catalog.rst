

Run every method family
-----------------------

This is the routing table for the complete method surface. Each row names
the constructor or token, a runnable example, and the primary literature.
The linked focused page explains the parameters without repeating that
material here.

Optimizers
~~~~~~~~~~

The session driver in ``examples/tutorial_session.rs`` is the minimal
runnable host loop. Replace its ``Method::lbfgs()`` expression with the
constructor in the second column. Dense Hessian methods use
``examples/tutorial_newton.rs``. The command for each is:

.. code:: console

    cargo run --locked --example tutorial_session
    cargo run --locked --example tutorial_newton

Manifolds and retractions
~~~~~~~~~~~~~~~~~~~~~~~~~

:doc:`manifolds` lists every ``ManifoldKind`` token, its packing,
projection, retraction, transport, Rust setup, and C setup. Run all
factory examples with:

.. code:: console

    cargo test --locked --test manifold_factories --test manifold_public_helpers
    python -m pytest python/tests/test_manifold.py -q

The QR and polar Stiefel retractions are ``StiefelRetraction::Qr`` and
``StiefelRetraction::Polar``. SPD uses
``SpdMetric::AffineInvariant`` or ``SpdMetric::LogEuclidean``. Products,
powers, subspace spheres, rigid quotients, and all token factories use
the same runnable page. The primary references are Absil, Mahony, and
Sepulchre, `10.1515/9781400830244 <https://doi.org/10.1515/9781400830244>`_,
and Boumal, `10.1017/9781009166164 <https://doi.org/10.1017/9781009166164>`_.
The mass weighted rigid layer follows Page and McIver,
`10.1063/1.454172 <https://doi.org/10.1063/1.454172>`_.

Krylov linear solvers
~~~~~~~~~~~~~~~~~~~~~

``gmres_right`` and ``gmres_right_block`` are unrestarted right-preconditioned
GMRES. ``GmresOptions::default`` is ``unrestarted(1e-8)``: the relative residual
tolerance is 1e-8, and ``max_iterations`` is unset, so the cap is the system
dimension. ``GmresStatus`` is ``Converged``, ``ZeroRightHandSide``, ``Exhausted``, or
``Stagnated``. A refusal is ``GmresFailure`` and carries a ``KrylovRefusal`` of
``EmptySystem``, ``Dimension``, ``Tolerance``, ``ZeroIterationBudget``, ``NonFinite``,
or ``SingularProjectedSystem``.

``fgmres`` is restarted flexible GMRES. ``Fgmres::default`` uses ``rtol`` 1e-8,
``restart`` 30, ``max_products`` 1000, and ``stagnation`` ``None``. ``FgmresStatus`` is
``Converged``, ``Exhausted``, ``Stagnated``, or ``Breakdown``.

``minres_solve_bounded`` and ``minres_solve_precond`` are matrix-free MINRES.
The bounded solve stops on a recomputed true preconditioned residual.
Saad and Schultz, `10.1137/0907058 <https://doi.org/10.1137/0907058>`_.
Saad, `10.1137/0914028 <https://doi.org/10.1137/0914028>`_.
