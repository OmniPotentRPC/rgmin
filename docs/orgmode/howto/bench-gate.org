* Compare repeated runs

~bench/gate~ reads the CSV written by ~bench/atomistic~ and decides
whether a candidate reached the same stationary point as a baseline in
fewer force calls. The comparison sits beside Goswami, AIP Adv. (2025),
doi:10.1063/5.0283639.

Install and run it with the pixi environment ~gate~ (numpy 2.2.6, scipy
1.15.3). Matplotlib is optional and is used only for ~--plot~.

#+begin_src bash
pixi run -e gate gate results.csv --pair lbfgs-exp=lbfgs-wolfe --pair fire-exp=fire --pair cg-exp=cg-wolfe
#+end_src

Exit 0 is a pass, 1 is a fail, 2 is undecided, and 3 is a contract or
argument error. The target is the win probability over the suite's
start distribution. A start is one ~(system, seed)~.

** Contract

A file with no version marker, or ~# rggate-csv 1~ (minor numbers
allowed), is contract version 1. Any other major version is refused.

Required columns:

~system,method,seed,converged,iters,calls,energy,fmax,wall_s~

Optional: ~pot_s~, ~overhead_us_per_iter~, ~endpoint~, ~reference~,
~dim~, ~threads~. ~dim~ is the free coordinate count, three times the
number of moving atoms. Frozen atoms are excluded, because ~fmax~ and
the energy bound cover only those atoms. ~reference~ is an energy, or
a path to an endpoint file. When ~reference~ is an energy, ~endpoint~
is not opened. When ~reference~ is absent or is a path, ~endpoint~ is
a structure path. An endpoint file has optional ~energy~ and
~cell~ lines, then ~x y z~. A zero cell is a free cluster.

** Same stationary point

Precedence on one start: an explicit ~reference~, then the baseline
endpoint from that start when the baseline converged, then the lowest
converged energy only with ~--reference lowest~. Otherwise the two
runs are compared with each other.

A free cluster is Kabsch-rotated after centering. A periodic cell is
not rotated: after the minimum-image map only the mean displacement is
removed. The energy window is ~--e-tol~ (default 1e-4 eV) when the atom
count ~N~ is unknown, and ~e_tol + N * max(fmax) * rmsd_tol~ when ~N~
is known from ~dim / 3~ or the endpoint. Each pair prints
~window_fallback~, the number of starts judged with the ~e_tol~
window. An energy-only split with unknown ~N~ is an upper bound on a
real basin split. Without endpoints the summary says ~energy-only~.

Per-method Kaplan-Meier curves and profiles count a converged run as a
success unless an explicit reference or ~--reference lowest~ is in
force. An unconverged run is right-censored at its call count. The
median interval is Brookmeyer-Crowley on the log-log Greenwood band
(Kaplan and Meier, JASA 53, 457, 1958,
doi:10.1080/01621459.1958.10501452).

** Profiles

Dolan-Moré at tau 1, 1.5, 2, 4 and 8 (Math. Program. 91, 201, 2002,
doi:10.1007/s101070100263). Moré-Wild at alpha 10, 50, 100, 500 and
1000 in force-call units, or ~alpha (n + 1)~ when ~dim~ is set (SIAM J.
Optim. 20, 172, 2009, doi:10.1137/080724083). Pairwise fractions when
more than two methods are present (Gould and Scott, ACM TOMS 43, 2016,
doi:10.1145/2950048).

** Calls and the walk

Both runs in the same basin form the BCa sample (Efron, JASA 82, 171,
1987, doi:10.1080/01621459.1987.10478410). The interval resamples
systems, then starts within each drawn system. It is printed when the
number of systems is at least ~--min-clusters~ (default 10). Below
that the cluster bounds are ~na~ and the i.i.d. interval is the
diagnostic. The geometric mean uses ~math.fsum~. ~n~ is the number of
same-basin starts. ~clusters~ is the number of systems in that sample.

A basin split (both converged, different basins) is counted with a
Clopper-Pearson interval and is not a loss. Gehan scoring handles the
rest: a candidate that stops early without converging does not win.
Indeterminate starts are dropped from the walk and counted.

Systems are shuffled with Philox, starts are shuffled within a system,
and a round robin visits one start from each system. The seed is mixed
into Philox key word 1. Stream and pair index sit in counter words 2
and 3.

With ~k~ pairs each walk uses ~alpha / k~. The header prints
~alpha_pair~. The default boundary is the normal mixture of Howard,
Ramdas, McAuliffe, and Sekhon, Ann. Stat. 49, 1055 (2021),
doi:10.1214/20-AOS1991, with ~V_t = t/4~. ~rho~ minimises the width at
~--plan-n~ (default 50) for ~alpha_pair~ and is printed. ~decide_min~
is the first number of informative starts at which an all-wins or
all-losses walk can cross. Before that count the pair line says
~forced=yes~. At the default horizon and one pair, ~decide_min~ is 11.
The walk stops when the interval excludes ~0.5 - --margin~. The
summary prints ~starts_used~ and the per-system win, loss,
indeterminate and split counts.

~--boundary agrapa~ uses one signed approximate-GRAPA stake from
Waudby-Smith and Ramdas, J. R. Stat. Soc. B (2024),
doi:10.1093/jrsssb/qkad009, clipped at 3/4 of full Kelly. It is not the
hedged capital process. The time-uniform guarantee is the sequential
test of Wald, Ann. Math. Stat. 16, 117 (1945),
doi:10.1214/aoms/1177731118.

~--jobs~ only splits the per-method Kaplan-Meier curves, then joins
them in method-name order. The bootstrap stays serial, and the summary
text is the same for ~--jobs 1~, ~2~, and ~N~.
