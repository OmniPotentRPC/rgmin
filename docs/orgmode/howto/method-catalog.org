the constructor or token, a runnable example, and the primary literature.

** Optimizers

The session driver in ~examples/tutorial_session.rs~ is the minimal
runnable host loop. Replace its ~Method::lbfgs()~ expression with the
constructor in the second column. Dense Hessian methods use
~examples/tutorial_newton.rs~. The command for each is:

#+begin_src console
cargo run --locked --example tutorial_session
cargo run --locked --example tutorial_newton
#+end_src

** Manifolds and retractions

@@rst::doc:`manifolds`@@ lists every ~ManifoldKind~ token, its packing,
projection, retraction, transport, Rust setup, and C setup. Run all
factory examples with:

#+begin_src console
cargo test --locked --test manifold_factories --test manifold_public_helpers
python -m pytest python/tests/test_manifold.py -q
#+end_src

The QR and polar Stiefel retractions are ~StiefelRetraction::Qr~ and
~StiefelRetraction::Polar~. SPD uses
~SpdMetric::AffineInvariant~ or ~SpdMetric::LogEuclidean~. Products,
powers, subspace spheres, rigid quotients, and all token factories use
the same runnable page. The primary references are Absil, Mahony, and
Sepulchre, [[https://doi.org/10.1515/9781400830244][10.1515/9781400830244]],
and Boumal, [[https://doi.org/10.1017/9781009166164][10.1017/9781009166164]].
For the mass weighted rigid layer, read Goswami et al. first,
[[https://doi.org/10.1021/acs.jctc.5c00866][10.1021/acs.jctc.5c00866]],
then Page and McIver,
[[https://doi.org/10.1063/1.454172][10.1063/1.454172]].
