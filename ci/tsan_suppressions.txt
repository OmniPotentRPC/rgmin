# ThreadSanitizer suppressions for ci/tsan_native.sh.
#
# A suppression belongs here only for a race inside the CPython runtime. A
# race with an rgmin, nanobind or NumPy frame is not suppressed: NumPy is
# built with the same sanitizer flags as the extension, so its own locks and
# atomics are visible to TSan, and an rgmin race is a bug to fix.
#
# Add one `race_top:<function>` line per function and say above it why the
# race is not ours: the CPython function, and the call from Python that
# reaches it. Do not suppress by module, and do not use a bare `race:` on a
# function that rgmin or NumPy can reach.

# CPython _decimal. The parallel test runner runs each worker thread inside a
# copy of one contextvars context, so every worker holds the same decimal
# context object. pytest.approx converts a float tolerance with
# Decimal.from_float, and dec_addstatus then ORs the status flags into that
# shared context with a plain write (Modules/_decimal/_decimal.c,
# `ctx->status |= status`). Reached only from pytest, never from rgmin.
race_top:dec_addstatus
